Hermes Assistant

A private, self-hosted personal automation assistant.

What this application is

Hermes Assistant is a personal automation tool that runs entirely on its owner's own computer. It is not a public service, it has no other users, and it is not distributed or offered for sale. It exists to help one household organise its own day-to-day life — a morning briefing, meal planning, and household reminders.

What it does

  • Reads the owner's own calendar to list the day's appointments in a morning summary.
  • Reads and sends email from the owner's own mailbox to deliver that summary to the owner.
  • Reads and updates a single private document that holds the household meal plan and shopping list.

How it connects

The application authenticates with Google using OAuth 2.0 and the owner's own explicit consent. It accesses only the owner's own Google account data. It does not access, request, or process data belonging to anyone else.

Data handling

All data stays on the owner's own hardware. The only thing stored is the OAuth credential used to talk to Google, kept in a local file readable only by the owner's account. Nothing is sent to any third party, and no analytics or telemetry of any kind is collected. Full details are in the Privacy Policy.
