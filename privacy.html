Privacy Policy

Hermes Assistant — a private, self-hosted personal automation tool.

Hermes Assistant is a personal application running on its owner's own computer. It has exactly one user: its owner. This policy explains which Google user data the application accesses, how that data is used, where it is stored, and with whom it is shared.

1. What Google user data is accessed

With the owner's explicit OAuth consent, the application requests access to the owner's own account only:

  • Gmail — read messages and send email, in order to deliver the owner's own daily summary to the owner.
  • Google Calendar — read events, in order to list the owner's own appointments in that summary.
  • Google Drive and Google Docs — read and update a single private document belonging to the owner that holds their household meal plan.
  • Google Sheets — read and write spreadsheets belonging to the owner, for household lists.
  • Contacts (read-only) — resolve the owner's own contacts when addressing mail.

The application does not access data belonging to any other person.

2. How that data is used

  • To generate and deliver a daily briefing email to the owner.
  • To maintain the owner's household meal plan and shopping list.
  • To read the owner's calendar so appointments appear in that briefing.

This is the sole purpose of the access requested. The data is used only for these functions and for nothing else.

3. Google API Limited Use disclosure

Hermes Assistant's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically:

  • Data is used only to provide the user-facing features described above.
  • Data is not transferred to third parties, except as necessary to provide those features, to comply with applicable law, or as part of a merger or acquisition with prior notice.
  • Data is not used for advertising, and is not sold.
  • Data is not used to train, improve, or develop machine learning or artificial intelligence models.
  • No humans read this data, except where the owner himself is the reader, or where required by law.

4. Storage and security

There is no server and no cloud database. All data processing happens on the owner's own computer. The only Google credential retained is an OAuth token, stored in a local file on that machine (~/.hermes/google_token.json) whose permissions restrict it to the owner's own user account. Email, calendar, and document content is processed in memory and is not retained beyond what is required to display it to the owner.

5. Retention and deletion

No Google user data is retained on any remote system. To revoke the application's access at any time, the owner can remove it from myaccount.google.com/permissions, or delete the local token file, which immediately ends all access.

6. Sharing

None. The application does not share, publish, transmit, or disclose any Google user data to any third party. It contains no analytics, no telemetry, no advertising, and no tracking of any kind.

7. Children

This application is not directed at children and is not intended for use by anyone other than its owner.

8. Changes to this policy

Any change to this policy will be published on this page with an updated date below.
